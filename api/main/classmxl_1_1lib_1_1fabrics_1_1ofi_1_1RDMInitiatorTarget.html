◆ shutdown()

void mxl::lib::fabrics::ofi::RDMInitiatorTarget::shutdown ( Endpoint &  ep)

Stop transfers to this target.

If writes are still outstanding, the target goes to the removing state. It keeps its address vector entry and its protocol instance until finishRemoval() finds that the writes have completed. Otherwise the address vector entry is removed right away and the target can be evicted.
