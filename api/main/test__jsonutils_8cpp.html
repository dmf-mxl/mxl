Convert a JSON number to the integer type T.

Converting a double that is outside the range of an integer type is undefined behavior in C++, so the value is checked before the conversion.

Parameters

nameThe field name, used in the error message.
Returns
The value as T.
Exceptions

Parse a JSON document with the limits in limits.

Unlike picojson::parse(value&, std::string const&), this rejects any content after the first value other than whitespace, and rejects objects with duplicate keys.
