Detailed Description

Non-owning single-producer event ring view safe for concurrent snapshot readers.

Metadata and payload are copied through atomic words; sequence tags detect overwrite during a read. The writer owns head advancement, timestamp validation and notifications. No shared tail or writer reservation cursor is stored here. The mapping must outlive this view and all calls through it.

Inspired by vt-tv/lockfree_ipc_ringbuffer revision ffd97a3cb0162109920af04408b54c2703aa9e4e; see docs/event-flows.md.
