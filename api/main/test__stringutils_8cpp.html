template<std::integral T>
T mxl::lib::jsonStringToInteger ( picojson::value const & value,
std::string_view name )
inline

Convert a JSON string holding a decimal number to the integer type T.

Use this for values such as memory addresses and keys, which are stored as strings because a JSON number is a double and cannot hold every 64-bit integer exactly.

Parameters
valueThe JSON value.
nameThe field name, used in the error message.
Returns
The value as T.
Exceptions
std::invalid_argumentIf the value is not a string, or not a decimal number in the range of T.
