Parameters
deadlineAbsolute realtime deadline for waiting; an expired deadline permits one attempt.
[out]infoMetadata destination, valid on success; must not be null.
[out]payloadReceives private snapshot storage on success; must not be null.
Returns
MXL_STATUS_OK, TOO_EARLY if unavailable by the deadline, TOO_LATE on overwrite, or FLOW_INVALID for corrupt metadata or a detected removed flow.
Note
Snapshot storage is reused by the next read attempt on this handle. Release must be coordinated with callers.
