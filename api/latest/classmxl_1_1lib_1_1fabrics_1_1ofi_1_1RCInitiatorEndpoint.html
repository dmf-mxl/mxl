The state that the endpoint goes to when a flush is complete.

Enumerator
Reconnect 

Go to the idle state and connect again. Used after an error event, when the target can still be running.

Disconnect 

Go to the disconnected state. Used after the target has closed the connection.

Done 

Go to the done state, so that the endpoint is evicted. Used after the target was removed.

)

Try to activate the endpoint.

The endpoint has an internal timer to slow down repeated failures to activate and/or connect. Until this timer has elapsed, the activation function will do nothing, and RCInitiatorEndpoint::isIdle() will return true. When the endpoint is eventually actived, it will have pending work until it is connected.

◆ finishFlush()

void mxl::lib::fabrics::ofi::RCInitiatorEndpoint::finishFlush ( )

Move the endpoint out of the flushing state when the flush is complete.

The flush is complete when a shutdown or error event was received and all operations that were outstanding at shutdown have completed, or when FlushTimeout has elapsed since the flush started. The endpoint then goes to the state that Flushing::next selects. In any other state, this is a no-op.
