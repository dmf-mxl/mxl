# Awesome MXL

This page is a collection of resources, references, and tools related to MXL.

* **MXL Tutorial**  
  Guided hands-on tutorial exploring MXL SDK [https://github.com/cbcrc/mxl-hands-on/blob/main/README.md](https://github.com/cbcrc/mxl-hands-on/blob/main/README.md)

* **OBS MXL Plugins**   
  A collection of OBS Studio plugins that enable integration with MXL (Media Exchange Layer) flows for real-time, uncompressed media sharing between applications. [https://github.com/samisb/obs-mxl-plugin](https://github.com/samisb/obs-mxl-plugin)

* **Proof of concept of MXL inter-host with RDMA**
  Results and methodology of experimentation with RDMA (RoCEv2) with the MXL Fabric that will (on roadmap for v1.1, as of 2026-04-17) enable media exchange between different hosts. [https://github.com/cbcrc/media-rdma-lab](https://github.com/cbcrc/media-rdma-lab)

* **MXL + NvNmos C API Example**
  Example applications combining the MXL SDK and [NvNmos](https://github.com/NVIDIA/nvnmos) to support AMWA [BCP-007-03](https://specs.amwa.tv/new/bcp-007-03/latest/) NMOS With MXL for connecting MXL readers and writers. [https://github.com/garethsb/mxl-nmos-c-example](https://github.com/garethsb/mxl-nmos-c-example)

\* Please note that the items here are not maintained by the MXL project, have not been validated for quality and are outside of the project.
